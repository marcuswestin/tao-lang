How this maps to real Tao. The engine here is a deterministic heuristic standing in for an LLM. In the real system it would live in the compiler's design module, read the existing design { description "..." } block, and emit the same token shape that tao-design-runtime and Views.tsx already consume (palette, accent, spacing, radius, type). Swapping the heuristic for a real model is an implementation detail behind one interface — everything you see rendering here is driven by that token output.
